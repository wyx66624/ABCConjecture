# General power-core theorem and square--cube horizon

For `n=prod p^e_p` and `k>=2`, put

\[
 U_k(n)=\prod_pp^{\lfloor e_p/k\rfloor}.
\]

Primewise,

\[
 k\lfloor e/k\rfloor\ge e-(k-1),
\]

so

\[
 U_k(n)^k\ge n/\operatorname{rad}(n)^{k-1}.
\]

If a primitive triple satisfies `c>R^(1+epsilon)`, where
`R=rad(abc)`, then `ab>=c-1` gives

\[
 U_k(abc)^k
 >c^{(3+2\epsilon-k)/(1+\epsilon)}(1-1/c).
\]

Thus a polynomially growing `k`-th-power core follows from the radical
violation alone exactly when

\[
 k<3+2\epsilon.
\]

For arbitrarily small `epsilon`, only the square and cube cores survive. Higher
fixed-power reductions need additional arithmetic input and cannot be obtained
from multiplicity extraction alone.
