# Exact refined-tensor Haar normalization audit

Run:

```text
python verify_refined_tensor_normalization.py
```

The script enumerates one through four primitive factors, with every
ramification index and residue degree from one through five.  Exact rational
arithmetic verifies total-local-degree normalization, relative-degree weight
normalization, the dimension-weighted factor formula, and conservation of
ten nonzero parent weights.  It also searches the same complete finite range
for failures of two stronger rules: division by the number of factors and
copying a parent tuple weight to every primitive factor.

`verification_output.json` is generated by the script.  `SHA256SUMS` seals
the script, output, and this README.  These computations audit finite
identities only.  They provide no evidence for the source-level theta
transport, Ind3 openness, the horizontal same-pilot comparison, IUT III
Corollary 3.12, IUT, or abc.
