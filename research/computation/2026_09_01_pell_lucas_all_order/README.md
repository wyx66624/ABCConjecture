# Pell--Lucas all-order computation bundle

This bundle supports
`research/ABC_PELL_LUCAS_ALL_ORDER_STAIRCASE_2026_09_01.md`.

* `produce_lucas_all_order_packet.py` creates the frozen JSON packet.
* `verify_lucas_all_order_packet.py` replays it with independent arithmetic.
* `lucas_all_order_packet.json` is the producer output.
* `lucas_all_order_verification.json` is the verifier output.
* `REPRODUCE.md` gives the commands and claim boundary.

The general theorems in the report are mathematical proofs.  These files
guard the specialized formulas and the numerical counterexample against
transcription and implementation errors.
