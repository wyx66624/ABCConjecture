# Formalization order for version 9

1. Formalize `U_k(n)` and the primewise exponent inequality.
2. Formalize the finite incidence double-count theorem.
3. Formalize the scalar canonical/noncanonical torsion-line cancellation.
4. Formalize the finite-free determinant-unit lemma over a DVR.
5. Formalize the three-point boundary theorem once a projective-curve
   Riemann--Hurwitz API is available; otherwise use a function-field
   Mason--Stothers proof.
6. Only after these pass the all-module kernel workflow, merge their Lean files.

The global specialization, IUT source, and final abc statements remain outside
this formalization cycle.
